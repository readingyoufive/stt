STT v10 WORKERFS — upload GitHub

1. Dézipper cette archive.
2. Déposer TOUT le contenu à la racine du dépôt, y compris le dossier .github.
3. Commit/push sur main.
4. GitHub > Settings > Pages > Source : GitHub Actions.
5. GitHub > Actions > ouvrir "Build STT demo and deploy Pages".

Le premier build :
- télécharge Parakeet v2 INT8 ;
- compile sherpa-onnx 1.13.5 avec WORKERFS ;
- publie le runtime .js/.wasm/.data séparément des trois fichiers ONNX ;
- déploie le site.

Aucune compilation n'est nécessaire sur le PC utilisateur.
