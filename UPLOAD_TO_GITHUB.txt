1) Dézippe cette archive.
2) Copie TOUT le contenu à la racine du dépôt GitHub, y compris .github/
3) Commit + push sur main.
4) GitHub > Settings > Pages > Source: GitHub Actions.
5) GitHub > Actions > ouvre "Build STT demo and deploy Pages".
6) Quand le job deploy est vert, ouvre l'URL Pages.

Aucune compilation locale n'est nécessaire.
