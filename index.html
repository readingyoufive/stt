Déploiement

Dépose simplement tout ce projet dans ton dépôt GitHub et pousse sur main. Le workflow .github/workflows/pages.yml construit sherpa-onnx 1.13.5 avec WORKERFS, publie le petit runtime séparément des poids ONNX, puis déploie GitHub Pages.

RTF = temps de calcul / durée audio. Un RTF de 0,20 signifie que 10 s d'audio prennent ~2 s à transcrire.
