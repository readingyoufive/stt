Déploiement

Pour GitHub Pages : pousse ce dossier dans un dépôt et active Settings → Pages → GitHub Actions. Le workflow fourni génère automatiquement le petit bpe.vocab nécessaire aux hotwords puis publie le site. Il ne compile pas sherpa-onnx.

RTF = temps de calcul / durée audio. Un RTF de 0,20 signifie que 10 s d'audio prennent ~2 s à transcrire.

Parakeet/hotwords reste marqué expérimental ici parce que le runtime navigateur précompilé utilisé est une intégration WebAssembly tierce autour de sherpa-onnx. Le modèle et le contextual biasing restent locaux après téléchargement.
